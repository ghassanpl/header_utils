Detailed Description

A buffer models a stream of byte-like elements that can be appended to.

The default, primary behavior is to append a single byte-like element to the buffer. Most other behaviors can be 'emulated' by repeatedly appending elements, but you are always free to provide your own overloads of the buffer_* functions. The default implementations will try to use methods/functions available in the standard library and its containers. Most functions return either the success boolean, or the number of elements successfully appended (in case of appending ranges).
