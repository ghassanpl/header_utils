FUNC && func )

Applies a cellular automata generation function on (a region of) the grid.

Note that since cellular automata operations are done on an immutable grid, this function creates a copy of the entire grid as the next generation, modifies it, and then swaps it with the current generation grid. Any iterators to the current (old) grid will therefore be invalidated and its data destroyed.
