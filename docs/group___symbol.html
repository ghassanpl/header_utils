Detailed Description

Interned strings; see description for details.

The symbol is a classic interned-string type that enables small storage sizes, content deduplication and quick comparisons, by only storing the (unique) pointer to a single instance of the string data. The specific operations of interning, hashing and comparisons are provided by a symbol_provider type parameter.
