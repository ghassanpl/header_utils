Detailed Description

Contains enum_flags, a value struct that represents a set of bits mapped to an enum (implemented as a bitset).

There also exists a C++98-only and C++17-only version of this module. See the <ghassanpl/cpp17/enum_flags.h> and <ghassanpl/cpp98/enum_flags.h> files.
