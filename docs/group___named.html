Detailed Description

Defines a 'strong typedef' template which is used extensively to create strongly-typed wrappers around other types.

By default, it needs to be explicitly constructed from its base type, and is not implicitly convertible to its base type. Most other operations need to be explicitly enabled via the TRAITS template parameter pack.
